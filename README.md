# Website for Cabinet Ibrahim Laghdas

This repository contains the complete source code for the official website of "Cabinet Ibrahim Laghdas," a law firm based in Tangier, Morocco.

## About the Project

This is a professional, responsive, multi-page website designed to present the law firm's services, expertise, and contact information to potential clients. The design is clean, modern, and consistent across all pages, adhering to a specific brand identity.

### Pages

*   **Homepage**: Features a hero section, a brief introduction to the firm, and client testimonials.
*   **About**: A detailed page about the lawyer, his experience, and the firm's values.
*   **Practice Areas**: A grid of cards showcasing the firm's areas of expertise.
*   **Contact**: A page with contact information, a contact form, and a map.

### Technologies Used

*   Next.js
*   TypeScript
*   React
*   CSS Modules

## How to Run the Website

To run this project locally, you will need to have Node.js and npm (or yarn) installed on your computer.

1.  **Clone the repository**:
    ```bash
    git clone https://github.com/your-username/your-repo-name.git
    ```
2.  **Navigate to the project directory**:
    ```bash
    cd your-repo-name
    ```
3.  **Install dependencies**:
    ```bash
    npm install
    ```
4.  **Run the development server**:
    ```bash
    npm run dev
    ```
5.  **View the website**: Open your web browser and go to `http://localhost:3000`.
